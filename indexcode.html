Server proxy (recommended for production & API keys)
Below is a minimal Node/Express proxy you can run (save as proxy.js) to forward requests and keep API keys secret. Start with node proxy.js. This is optional — the UI works client-side for public endpoints (ChEMBL, MyGene, KEGG) but some APIs require CORS or keys.

const fetch = require('node-fetch');

const app = express();
app.use(cors());
app.use(express.json());
