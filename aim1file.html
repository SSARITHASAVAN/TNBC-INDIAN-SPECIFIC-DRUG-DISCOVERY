Notes & Deployment
  1. This single-file app runs fully client-side for parsing, normalization (MyGene.info) and ChEMBL reads. Some APIs may block CORS — for production host a small proxy (Node/Express) that stores API keys and forwards requests. Example proxy endpoints are referenced in the code comments.
  2. Retrosynthesis requires a server-side API key and is implemented here as a call to `/api/retrosynth` — implement that endpoint in your Node/Express proxy to call ASKCOS/AiZynth/PostEra.
  3. Pathway enrichment uses Reactome and KEGG public endpoints. For heavy usage, cache results server-side.
  4. To publish: commit this file as index.html to a GitHub repo and enable GitHub Pages (or host behind a small server for proxy endpoints).
